PARTS view: click/drag paints the body part, F toggles flood fill (fills same palette index + same part), Tab switches LEFT/RIGHT, Shift+click picks, keys 1-0/q/e/x pick parts. Keys: A/D or arrows = prev/next, Ctrl+Z / Z undo, Ctrl+Y / Ctrl+Shift+Z / Shift+Z redo, V violations only, K no stick, O labels, J skeleton, N skeleton tags (H, LH/RH, LK/RK, LF/RF, SHAFT, BLADE), Z undo, S save, part keys on the buttons.
