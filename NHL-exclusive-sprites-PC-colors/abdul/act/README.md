# Abdul's guide palettes (ACT)

| file | what it is | used by the tools |
|---|---|---|
| `abdul_palette_complete.act` | **Abdul's complete guide palette**, the default (`tools/paths.py` `GUIDE_ACT`, override with `NHL_GUIDE_ACT`). Same colours as `../abdul_palette.bmp` on every index the BMP uses, plus 135 (160,96,96) skin dark, 164 (74,173,134) goalie mask and 178 (0,170,0) pants stripe 2. All 48 zones 144–191 have unique colours (170 is (170,170,170)). Indices still at the grey placeholder (i,i,i) outside 144–191 are not guide colours: the sheets show them in cyan. | yes |
| `abdul_palette_complete_255purple.act` | the same, with 255 (transparent) as (90,0,90) instead of white | no |
| `abdul_palette_old_grey_placeholders.act` | older version: 135, 164 and 178 are still grey placeholders | no, kept for history |
| `other_51col_a.act`, `other_51col_b.act` | two 51-colour palettes that are not part of this work (ACT trailer: 51 colours) | no |
